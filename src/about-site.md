# {{ title }}

Originally, a shortened version this information lived on the homepage right in the first paragraph,
but I've began to feel that's a bit too distracting and irrelevant to what my site is about.
Still, I want it to be detailed somewhere, after all I'm a person interested in technology and while web development isn't something I know much about, it's still fun to share my endeavours.

Primarily, this is SSG site made with Build Awesome (formerly known as Eleventy).
Nearly every page is wrote in Markdown and as you can likely tell it's being hosted with GitHub pages (well, except for the time I ran it over [packet radio](/packet-radio)).
So... nothing radically interesting or different behind it's tech stack.

I'd wanted to make a website for quite some time before starting this one back around Christmas 2025, but I'm not a web developer.
I ended up learning enough to hack it together thanks to the Odin project and watching tutorials for Jekyll's site generator, which I intended to use before I arrived on Eleventy.

I ended up choosing Eleventy as it pretty much strictly restrains itself to being an SSG.
Design and aesthetics are purely the users domain! I wanted my site to be of my own design, not taking another's theme.
I also liked that it was using the prominent and easy (dare I say that for a language with as nasty a feature as hoisting?) language JavaScript, as oppose to something I'd have less use for like Ruby or PHP.

There is a minor concern in the back of my mind about the name and direction change to "Build Awesome", but my site is so simple that porting to another generator should be a weekend job if it all goes pear shaped. I'd probably move to Hugo or Jekyll, I experimented with Astro, but the default initialisation makes a _AGENTS.md_ file for you, YUCK!!! The AI hype train can't die fast enough for me.

Still, as a consequence of the styling being fully in my hands, you can tell my site is pretty plain, I'm basically at the limit of my HTML/CSS knowledge.
But also this is intentional; The site's design matches the spirit of my appreciation for fast, performant and minimalist leaning software that gets the job done well, and it has a certain mid-naughties nostalgia of how people's personal sites looked like when I was first on the internet. The design is very me, and I like it a lot!

I did make a special effort to better support smaller screens and preferred dark mode though, I'm not _completely_ against modern innovations.
